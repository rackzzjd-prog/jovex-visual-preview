# Future standalone previews

Keep each future preview in its own named subdirectory, for example `previews/next-study/index.html`. Include only standalone public-safe files and required licensed assets. Do not copy application repositories, environment files, credentials, private data, node_modules, or server code.

The eight original experiments remain unchanged at `/index.html`. Adding a future preview does not require replacing the root gallery. Use relative paths for any future assets so project-site URLs work correctly.
