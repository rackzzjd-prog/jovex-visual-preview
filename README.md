# JOVEX Visual Preview

A standalone, public-safe gallery of eight original interactive UI experiments. The experiments have not been rebuilt, redesigned, or replaced.

## Files

- `index.html`: complete original gallery; embedded CSS, JavaScript, and two public-domain photographs. No install or build required.
- `.nojekyll`: tells GitHub Pages to serve the files directly.
- `ASSET-CREDITS.md`: photography sources and original lab provenance.
- `previews/README.md`: conventions for adding future independent previews without changing this gallery.

## Eight originals

| ID | Experiment |
| --- | --- |
| 01 | Immersive floating 3D gallery |
| 02 | Cinematic photographic hero with layered depth |
| 03 | Animated interactive portfolio |
| 04 | Product/device mockup with working interface |
| 05 | Scroll-driven experimental typography |
| 06 | Interactive service cards with pointer and touch effects |
| 07 | Spatial dashboard with functional controls |
| 08 | Iris, diagonal masking, and parallax transitions |

All eight are accessible through the labeled Open experiment buttons. Mobile fallbacks, keyboard controls, and reduced-motion handling are preserved. No accounts, analytics, inquiry backend, or private dependencies are included.

## Enable GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Choose **main**, folder **/ (root)**, and **Save**.
4. Wait for the **pages build and deployment** Actions run to finish.
5. Use **Visit site**, or open `https://rackzzjd-prog.github.io/jovex-visual-preview/` in Safari.

The address above is the expected Pages URL; it is not a claim that Pages is enabled or publicly verified. This repository is separate from the JOVEX production website.
